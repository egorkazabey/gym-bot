# Gym bot

Telegram-бот для записи тренировок: пишешь `жим 80x8x3`, он сохраняет, сравнивает с прошлым разом, ловит рекорды и рисует графики.

## Запуск локально

```bash
pip install -r requirements.txt
cp .env.example .env      # вставь BOT_TOKEN и свой ID в ALLOWED_USERS
python bot.py
```

## Форматы записи

| Пишешь | Значит |
|---|---|
| `жим лежа 80x8x3` | 3 подхода по 8 с 80 кг |
| `жим 80х8` | 1 подход (русская «х», `*` и `×` тоже работают) |
| `жим 82,5x8x3` | дробный вес |
| `жим 80x8,8,7` | разные повторы по подходам |
| `жим 80x8x2 85x6` | несколько групп в одной строке |
| `подтягивания x10x3` или `бв10x3` | свой вес |
| `подтягивания +10x8x3` | с доп. весом |

Несколько упражнений в одном сообщении, каждое с новой строки.
Если первой строкой написать `вчера`, `позавчера` или `28.09`, запись уйдёт на эту дату.

## Команды

`/today` `/week` `/last жим` `/history жим` `/progress жим` `/pr` `/list` `/alias жим = жим лежа` `/undo` `/export`

Название упражнения в командах можно писать частично: `/progress подт` найдёт подтягивания. Без аргумента бот покажет кнопки.

## Файлы

- `bot.py` хендлеры и запуск
- `parser.py` разбор сообщений, формула 1ПМ (Эпли)
- `db.py` SQLite
- `charts.py` графики matplotlib

## Хостинг

Нужен только `BOT_TOKEN`, работает на long polling, вебхук не нужен. На хостинге важно, чтобы `DB_PATH` указывал на папку, которая не стирается при обновлении кода, иначе история тренировок пропадёт после деплоя. Делай `/export` время от времени как бэкап.
