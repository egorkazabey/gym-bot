# Gym bot

Telegram-бот для записи тренировок: пишешь `жим 80x8x3`, он сохраняет, сравнивает с прошлым разом, ловит рекорды и рисует графики.

## Запуск локально

```bash
pip install -r requirements.txt
cp .env.example .env      # вставь BOT_TOKEN и свой ID в ALLOWED_USERS
python bot.py
```

## Форматы записи

| Пишешь | Значит |
|---|---|
| `жим лежа 80x8x3` | 3 подхода по 8 с 80 кг |
| `жим 80х8` | 1 подход (русская «х», `*` и `×` тоже работают) |
| `жим 82,5x8x3` | дробный вес |
| `жим 80x8,8,7` | разные повторы по подходам |
| `жим 80x8x2 85x6` | несколько групп в одной строке |
| `подтягивания x10x3` или `бв10x3` | свой вес |
| `подтягивания +10x8x3` | с доп. весом |

Несколько упражнений в одном сообщении, каждое с новой строки.
Если первой строкой написать `вчера`, `позавчера` или `28.09`, запись уйдёт на эту дату.

## Команды

`/today` `/week` `/last жим` `/history жим` `/progress жим` `/pr` `/list` `/alias жим = жим лежа` `/undo` `/export` `/app`

Название упражнения в командах можно писать частично: `/progress подт` найдёт подтягивания. Без аргумента бот покажет кнопки.

## Файлы

- `bot.py` хендлеры и запуск
- `parser.py` разбор сообщений, формула 1ПМ (Эпли)
- `db.py` SQLite
- `charts.py` графики matplotlib
- `webapp.py` бэкенд мини-аппа (aiohttp, JSON API)
- `webapp/index.html` сам мини-апп

## Мини-апп

Внутри Telegram открывается дневник: сводка за неделю, карта активности, список упражнений с графиками прогресса и историей, форма записи тренировки (формат тот же, что и в чате).

Мини-апп работает в том же процессе, что и бот: при заданном `WEBAPP_URL` бот поднимает веб-сервер на порту `PORT` и ставит кнопку «Дневник» в меню чата. Ещё его можно открыть командой `/app`.

Telegram открывает мини-аппы только по **https**, поэтому нужен публичный адрес:

- на хостинге (Railway, Render, Fly.io и т.п.) открой порт `PORT` наружу и впиши выданный домен в `WEBAPP_URL`, например `https://gym-bot.up.railway.app`
- локально подойдёт туннель: `cloudflared tunnel --url http://localhost:8080`, адрес из его вывода вставь в `WEBAPP_URL` и перезапусти бота

Каждый запрос мини-аппа подписан Telegram (initData), сервер проверяет подпись токеном бота, так что чужие данные не увидеть. `ALLOWED_USERS` действует и здесь.

## Хостинг

Нужен только `BOT_TOKEN`, работает на long polling, вебхук не нужен. Для мини-аппа дополнительно нужен `WEBAPP_URL` и открытый порт (см. выше). На хостинге важно, чтобы `DB_PATH` указывал на папку, которая не стирается при обновлении кода, иначе история тренировок пропадёт после деплоя. Делай `/export` время от времени как бэкап.
